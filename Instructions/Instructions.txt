Redesign a mobile-first Expo/React Native personal home-management app. The current app has a dark, utilitarian style with deep navy/slate backgrounds, rounded cards, cyan primary actions, green success/add actions, red destructive states, muted gray secondary text, and Material-style outline icons. Keep the same product structure and workflows, but create a more polished, modern, cohesive visual design.

The app has these screens:

1. Login / Register
A full dark background screen with a language selector at the top using two pill buttons: English and Romanian. Below is a header reading “Organize My Wardrobe” with a short subtitle. The form sits in a rounded dark card with uppercase field labels, email and password inputs, a primary cyan login/create-account button, a secondary outlined toggle button, validation errors, and a muted footer line.

2. Tutorial / Onboarding
A full-screen onboarding carousel over a wardrobe photo background. There is a top-right “Skip” action, three horizontally swipable slides, each with a large centered rounded dark card containing welcome text. The footer has pagination dots and a full-width primary button that changes from “Next” to “Get started.”

3. Home
A simple split-screen module selector with two large vertical tappable halves. The top half is Wardrobe, teal-blue, with a large wardrobe-outline icon, title, and centered subtitle. The bottom half is Fridge, green, with a large fridge-outline icon, title, and centered subtitle.

4. Wardrobe Library
A dark inventory screen with a title, subtitle, optional active try-on badge, tag filter pill, expandable filter chips, grid/list view icon toggle, and green “+ Add new item” button. Items appear as rounded image cards in either list or two-column grid. Each wardrobe card has a clothing photo, item title, description, color metadata, and pill actions: Edit, Try on / remove from try-on, Delete. Empty states and pagination appear at the bottom.

5. Add / Edit Wardrobe Item
A scrollable form screen with title and subtitle, then a rounded dark form card. Fields include title, description, image URL, optional Google Drive folder image picker, upload image button, image preview, color, and tag selector. Tags are shown as selectable pills with a “Manage tags” action, add-tag input, and delete controls. Save is a prominent pill button; Cancel is a text link.

6. Try On
A wardrobe outfit builder screen. Header has title, subtitle, and a green “Suggestion” button. The main content is organized into three sections: Top, Middle, Bottom. Each section contains draggable clothing image tiles in a responsive grid. Each tile has an image, title, layer chips, and delete action. Below is a “Save configuration” area with a text input, save button, saved configuration chips, active state, and delete configuration action.

7. Fridge Contents
Similar to Wardrobe Library but for food inventory. Header includes title, subtitle, segmented pills for Current / History, filter tags, grid/list toggle, and two actions: “+ Add fridge item” and “+ Add receipt.” Food cards show image, name, description, quantity, expiration date, calories, and actions such as Edit, History, or Add back. History mode changes available actions. Includes empty states and pagination.

8. Add / Edit Fridge Item
A scrollable dark form card with fields for name, description, quantity, calories, expiration date, image URL or upload image, image preview, quantity type dropdown, tag selector, and a green save button. Inputs are compact, rounded, and dark with uppercase labels.

9. Add Receipt
A receipt import flow. Header has title and Cancel pill. A subtitle explains uploading a receipt photo for AI extraction. There is a primary upload button, optional loading indicator, receipt image preview, extracted item chips, and a completion form for each extracted item with fridge item fields, quantity type selector, tags, and save button.

10. Recipes
A list screen with title and “+ Add recipe” button. Recipe cards are rounded dark panels showing recipe name, calories, portions, and grouped ingredient chips: green chips for “In fridge” and red chips for “Need to buy.” Each card has an Edit pill. Pagination is fixed at the bottom.

11. Recipe Details / Recipe Form
Recipe details show title, calories, portions, instructions, “In fridge” ingredients, “Need to buy” ingredients, and a back button. Add/edit recipe forms contain dark inputs for name, instructions, calories, portions, an ingredient picker with item chips and info buttons, quantity input, ingredient list, modal item preview, and green save button.

12. Assistant Chat
A chat screen with title and subtitle, empty-state card, assistant/user message bubbles, and a bottom composer. User messages are cyan and right-aligned; assistant messages are dark card bubbles and left-aligned. Composer has multiline input and a cyan Send button.

13. Settings
A dark settings screen with title, signed-in email, language segmented buttons, AI connection segmented buttons for Local network / Cloud, optional API key input and save button, saved confirmation text, and a primary Sign out button.

Navigation:
The app uses bottom tabs with dark tab bar, cyan active icon/text, muted inactive icons. Main tabs are Home and Settings. Wardrobe module tabs include Home, Wardrobe, Try on, Assistant, Settings. Fridge module tabs include Home, Fridge, Recipes, Assistant, Settings.

Design direction:
Create a premium, calm, mobile-first redesign for a practical inventory app. Preserve the workflows and screen hierarchy, but improve spacing, typography, component consistency, icons, empty states, cards, filters, forms, tab navigation, and visual hierarchy. Keep strong support for image-heavy wardrobe and food cards. The app should feel organized, personal, modern, and easy to scan, with clear module distinction between wardrobe and fridge.
